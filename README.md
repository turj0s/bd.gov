# Bangladesh Government Portal Redesign (Frontend Prototype)

Polished, responsive UI/UX concept for a modern Bangladesh National Portal homepage.

## Run locally

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173`.

## Features

- Refined visual design with cleaner spacing, hierarchy, and card system
- Responsive layouts for desktop, tablet, and mobile
- Mobile navigation toggle + dropdown menu structure
- Search flow for services, ministries, links, and notices
